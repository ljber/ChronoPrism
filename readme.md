# ChronoPrism - A complete, work-in-progress vibecoded raytracing lab!



## How to run:



### Linux:

Mostly everything should be installed. All you will have to do is clone this repository and install the required packages (sounds simple enough, right?):



`git clone https://github.com/ljber/chronoprism`

`cd chronoprism`

`pip install -r requirements.txt`

> On some Linux distros (macOS users are not concerned), it will give you an error about system packages or something like that. In that case, you can look up how to set up venv to safely install pip packages, or just use `sudo apt install python3-(packagename)`

`python3 chronoprism.py`




### Windows

Install python from ![here](python.org)

Download the ZIP file from GitHub

Extract the ZIP file

type `cmd` in the file address bar in Explorer

`pip install -r requirements.txt`

`py chronoprism.py`
